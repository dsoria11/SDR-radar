# SDR-Radar-and-GUI
Developing an SDR enabled UHF Radar System with GUI. UNM Senior Design Spring/Fall 2026

# Instructions to Run Code
1. SSH into the remote server to get access to bladeRF.
   ```bash
   ssh username@address
   ```
2. Using a miniconda terminal to activate virtual environment 	
   ```bash
	source venv/bin/activate
   ```
3. Run the main program
   ```bash
   python main.py
   ```
